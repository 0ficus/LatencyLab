Проблема // 01

Профайлер отвечает на «где»,
но не на «почему»

где
функция
foo()
Профайлер показывает: время уходит сюда. Но не говорит, из-за чего именно.
почему
cache misses
 ветвления…
Latency Lab находит настоящую причину задержки и объясняет её словами.
время→ показатели CPU→ участки кода→ гипотезы
Идея // 02

Запускаем эксперименты —
получаем объяснение

Инструмент гоняет программу через серию измерений и на выходе даёт не таблицу чисел, а понятный ответ: вот отсюда задержка — и вот почему. Каждая гипотеза привязана к следующему эксперименту, который её проверит.

1 запустить→ 2 измерить→ 3 объяснить
Что сделали // 03

Единый инструмент —
от запуска до диагноза

Python TUI→ C++ runner→ программа
Textual TUI
Экран результата и панель «Диагноз»
C++ runner
fork/exec, affinity на CPU, timeout
MetricsCollector
Счётчики через perf_event_open + ресурсы из wait4
Анализ
Статистика, CPI, гипотезы, сравнение версий

Метрики: время, cycles, instructions, cache misses, task_clock · ресурсы: user/system CPU, page faults. Без изменения вашего кода.

Диагностика // 04

Пять слоёв объяснимого анализа

01
Статистика
Среднее, min/max, медиана, разброс и коэффициент вариации.
02
Показатели CPU
CPI, доля промахов кеша, backend/frontend-простои.
03
Сравнение A/B
Медианы базовой и новой версий, одинаковый объём работы.
04
perf-профиль
Сэмплы CPU / cache-misses, топ-5 горячих строк с исходником.
05
ИИ-диагноз
LLM читает горячий код и метрики — предлагает эксперименты.

Гипотезы требуют проверки экспериментом — мы не выдаём «вероятность причины», а показываем, что проверить дальше.

Честно об ограничениях // 06

Главное ограничение — perf

Счётчики запрещены
Linux отдаёт perf_event_open: Operation not permitted (paranoid=2).
Причина — гипотеза
Аппаратные причины (cache misses) пока не доказаны числом — только косвенно.
Что измерено реально
Время, user/system CPU и page faults — честные, без подстановок.
Сверка ещё впереди
Сравнение с perf stat на свободной машине не выполнено.

Недоступная метрика показывается как «недоступна» с причиной — мы не придумываем числа.

Дальше // 07

Следующий шаг

01
